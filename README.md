Selamat datang di repositori resmi **Proyek 3 - Pengembangan Aplikasi Smart Urban Health**. Proyek ini dirancang untuk mengintegrasikan teknologi *Machine Learning* dan *Intelligent Chatbot* guna menghadirkan solusi layanan kesehatan masyarakat yang responsif, cerdas, dan efisien dalam ekosistem tata kota cerdas (*Smart City*).

---

## 📌 Gambaran Umum Proyek

Aplikasi ini berfokus pada digitalisasi dan optimasi layanan kesehatan tingkat pertama melalui pendekatan berbasis data. Dengan menggabungkan performa sistem backend yang kokoh, antarmuka mobile yang modern, dan kecerdasan buatan, proyek ini menawarkan solusi untuk akurasi triase medis dan interaksi asisten kesehatan virtual yang interaktif.

### Fitur Utama:
*   **Intelligent Health Chatbot:** Asisten virtual interaktif berbasis NLP (Natural Language Processing) untuk konsultasi awal gejala, memberikan informasi medis dasar, dan panduan layanan kesehatan secara real-time.
*   **Machine Learning Diagnostics & Triage System:** Sistem pendukung keputusan (Decision Support System) memanfaatkan model Machine Learning untuk menganalisis data klinis awal guna menentukan tingkat urgensi penanganan (triase).
*   **Premium & Modern User Interface:** Desain antarmuka pengguna yang dirancang dengan estetika tinggi, mengutamakan kejelasan visual, kenyamanan navigasi, dan pengalaman pengguna (*UX*) yang *seamless*.
*   **Robust API Ecosystem:** Integrasi arsitektur back-end yang andal untuk manajemen data, autentikasi, dan menjembatani model AI dengan aplikasi mobile secara aman.

---

## 🛠️ Arsitektur & Teknologi

Proyek ini dibangun menggunakan *clean architecture* dengan kombinasi *tech stack* berikut:

*   **Mobile Client:** `Flutter` (Dart) – Menyediakan UI/UX yang modern, responsif, dan performa *native* yang mulus di platform mobile.
*   **Back-end API:** `Laravel 11` (PHP) – Berperan sebagai core engine untuk manajemen database, business logic, keamanan, dan penyediaan RESTful API yang cepat.
*   **AI/ML Engine:** `Python` – Digunakan untuk riset, pelatihan model, evaluasi, hingga deployment API model *Machine Learning* dan *NLP Chatbot*.
